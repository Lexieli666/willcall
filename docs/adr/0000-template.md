## Context

What forced a decision. Include the measurement or constraint that made the question real; an
ADR whose context is "it seemed nicer" is a preference, not a decision.

## Decision

What was decided, stated so that a reader can tell whether the code follows it.

## Alternatives considered

Each rejected option with the reason it lost. "Not considered" is a legitimate entry when an
option was ruled out by a constraint; say which constraint.

## Consequences

What this makes easy, what it makes hard, and what has to be revisited if an assumption
changes.

## Falsifier

The test, job, query, or measurement that would show this decision is being violated or was
wrong.
